Eda & Yağız — 6. Ay | VS Code projesi

1) Bu klasörü VS Code'da açmak için Eda-Yagiz-6-Ay.code-workspace dosyasına çift tıkla.
2) Terminali açıp npm install yaz.
3) Ardından npm run dev yaz; çıkan adresi tarayıcıda aç.

Düzenleme yerleri:
- src/App.jsx: sayfalar, metinler ve etkileşimler
- src/styles.css: renkler, kartlar ve animasyonlar
- index.html: tarayıcı sekmesi başlığı

Spotify bağlantısını src/App.jsx içinde PLAYLIST_LINKINI_BURAYA yazarak bulup değiştir.

Not: Bu React projesi index.html'e çift tıklayarak çalışmaz. Önce npm install gerekir. Daha sonra GitHub'a yüklemek için klasörün içindeki proje dosyalarını kullanabilirsin.
